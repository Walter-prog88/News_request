第 7 课 · 不许一步跑太远:TRPO 与 PPO 的 clip

上一课那 5 个乱跳的数字是病;这一课只讲药

本课只讲一个问题:怎样降低一次策略更新过大的风险。 TRPO 是第一代答案(一眼带过),PPO 的 clip 和 min 是重点(讲透)。

明确不讲:GRPO(下一课)、熵正则与探索(欠账记着,之后单独还)、RL 怎么搬到 LLM 上(下下课)。

病历回顾(上一课的结尾)

ratio = 90 意味着每采到一次「上」,这一条样本要当 90 条用。 结果就是你亲手跑出来的:5 组估计在 −0.14 到 17.86 之间乱跳,全看运气抽到几次「上」。 你自己总结过这条链:"策略更新过大 → ratio 极大 → 一条稀有样本被放大 → 训练崩。"

先把"要最大化的东西"拼出来

上一课 E[ratio × R] 的用途是估计——旧样本在手,估新策略能拿几分。 训练要的是另一个用途:把这个数推高。三步,全是旧零件:

步做什么来自
1想推高的是新策略的平均回报 Enew[R]第 2 课
2手里只有旧样本 → 改写成 Eold[ratio × R]。上一课你是"看"这个数(估计),现在要"推"它(最大化)——式子没变,身份变了第 6 课
3R 换成 A = R − V:减基线不改"谁最大"(在这个世界里只是整个目标平移一个常数 Vold),方差更小第 3 课
拼好的目标(论文里叫 surrogate objective,代理目标):  最大化  Eold[ ratio × A ]

现在可以正式提问了:朝这个目标猛冲,ratio 就会冲成 90,翻车如上。 怎样在算法里降低"更新过大"的风险?历史上有两代答案。

二第一代答案:TRPO —— 立规矩

TRPO(2015,Trust Region Policy Optimization,信任区域策略优化)的思路是直接立法:

最大化  E[ ratio × A ]  (刚拼好的代理目标)
附加一条硬约束:新旧策略的 KL 距离  KL(πold, πnew) ≤ δ（此处是一状态示意）

KL 散度是什么?今天只需要记名字:它是衡量两个概率分布差多远的一个数,分布相同时为 0,差得越远越大。 本课把它当黑盒。讲 RLHF 那课它会以 "KL 惩罚" 的身份正式回来,到时候再拆开。

"信任区域"这个名字说的就是:以旧策略为圆心,画一个半径 δ 的圈,新策略只许在圈里选。KL 约束用于限制整体分布变化；即使 KL 较小，低概率动作的 ratio 仍可能很大。实际 TRPO 使用平均 KL 近似约束与线搜索，不能把它当作每个动作概率比的硬上限。

思路很干净,但带约束的优化没法直接交给"算 loss → backward"这条流水线(接口课的流水线)。 求解要用二阶导数、共轭梯度这些重型机械——实现难、算得慢、对大网络很不友好。所以 2017 年 PPO 出来后,几乎所有人都换了。

TRPO(2015)PPO(2017)
手段硬约束:KL ≤ δ改目标函数:越界的好处直接裁掉
求解二阶方法,复杂笨重照常 loss → backward,一行都不用改
地位论文里的祖师爷,常被引用实际训练的默认选择(包括 LLM)

三第二代答案:PPO —— 让越界无利可图

PPO(Proximal Policy Optimization,近端策略优化;proximal = "就近")的观察是: 与其立法禁止越界,不如让越界捞不到任何好处。做法是把刚拼好的代理目标改成:

JCLIP = E[ min( r·A, clip(r, 1−ε, 1+ε)·A ) ]
■ E[·] 期望≈采样平均(第 2 课) ■ r = πnew/πold(第 6 课) ■ A 优势(第 3 课) ■ min、clip、ε 新零件:两个函数 + 一个超参数

先别慌。这条公式你已经认识 80%:E 是第 2 课的、r 是第 6 课的、A 是第 3 课的。 真正的新东西只有两个初中函数:

新零件 1:clip —— 一把夹子

clip(x, 下限, 上限):x 在范围内就原样放行,超出就按边界算。三个例子(取 ε = 0.2,即范围 [0.8, 1.2]):

clip(90, 0.8, 1.2) = 1.2   |   clip(1.05, 0.8, 1.2) = 1.05   |   clip(0.3, 0.8, 1.2) = 0.8

对 clip(r) 这个候选项，90 会被替换为 1.2。这不表示实际 ratio 被限制在 1.2 以内；PPO 还要比较未裁剪项，依据优势的正负决定哪一侧进入平台。

新零件 2:min —— 永远挑对自己更不利的那个

公式里摆了两个候选:没裁的 r·A 和 裁过的 clip(r)·A,然后取 min—— 两个里挑小的,也就是挑更悲观的那个。为什么必须这样,光看文字不直观,下面亲手拖一遍。

先记住结论,再去验证:min 的效果是——占便宜的方向封顶,犯错误的方向不封。 往"目标变好"的方向越界,好处到 1±ε 就到头了;往"目标变坏"的方向越界,罚单全额保留,一分不减。

四动手:clip 到底在裁什么,min 到底在防什么

一条样本的目标值 L = min( r·A , clip(r)·A )

选一条样本(动作和它的 A 来自上面设定表),拖动 r 和 ε,看三个数怎么变。 灰线是不设防的 r·A(没加任何保护的代理目标),绿实线是 PPO 实际用的 L。平的地方 = 斜率为 0 = 这条样本推不动网络了。
一个要点:设定表里「上」的 ratio=90 是"一步跳到终点"才会出现的数;训练中 πnew 是被一步步推着挪的, 这根滑块拖的是"此刻挪到哪了"——你会看到刚过 1+ε 就已经无利可图,90 根本轮不到出场。

最后一行就是"去掉 min"按钮让你看的东西。只用 clip 不取 min, 在这条 A<0 的样本上，若概率被推高越界，只用 clip 会让该样本的目标进入平台。 min 保留未裁剪项对此样本的修正梯度；这描述的是单样本目标对 r 的局部斜率，不保证共享网络的总梯度、真实回报或最终更新方向。

和神经网络怎么接?接口课的 Actor loss 是凑出来的 -logp * A。PPO 只是再换一次式子:

 loss = -logp * A                       # 接口课的版本
 loss = -min(r*A, clip(r, 1-ε, 1+ε)*A)  # PPO 的版本
 loss.backward()                        # 这一行永远不变

慢着——接口课的 logp 去哪了?梯度从哪进网络?把 r 拆开就看到了:

分子 πnew(a) 网络此刻的输出,活的——参数一动它就动,梯度就是从这里流进网络的(它就是接口课里的 p[a],logp 是它的对数)
分母 πold(a) 采样那一刻存档下来的常数,死的——backward 不碰它

所以"L 对 r 的斜率"就是流回网络的推力;曲线平了 = 这条样本给网络的推力为 0。 实现里常写 r = exp(logp_new − logp_old)——logp 没有消失,只是搬进了 r 里。

PPO 的裁剪代理目标可以用常规一阶优化器更新。这使实现通常比 TRPO 的约束优化简单；最终性能仍取决于任务、采样、价值估计与优化设置，不能归结为一个原因。

"有偏"到底偏掉了什么、"稳"又稳住了什么,把四个动作的账摊开看(情形 B,每采到一条该动作的样本记多少分):

波动较小不等于估计正确，更不等于更新方向正确。 −0.67 与真实均值 8.86 连符号都不同。权重截断虽然保留了各项的正负号，却改变了相对大小，因此总估计、总梯度和动作排序都可能改变。这个实验只展示一种偏差与方差的取舍，不能据此解释为 PPO 保住方向或锁住步长。

六那还怎么到 0.90?小步快跑

一个容易产生的误解是：clip 让新策略只能在旧策略的 ±ε 内移动。PPO 的 clip 是代理目标的激励截断，不是概率比或 KL 的硬约束。下面另外人为规定每轮概率乘以 (1+ε)，只用来说明“反复小步也能累计成大变化”；这不是 PPO 优化器的实际轨迹。

从 π(上) = 0.01 走到 0.90,每轮最多把概率放大 (1+ε) 倍

这是人为设定的乘法演示：每轮更新后的概率成为下一轮的起点。
"最多 ×(1+ε)"是哪来的:ratio ≤ 1+ε 就是 πnew(上) ≤ (1+ε) × πold(上),每轮把好处吃满,概率正好 ×(1+ε)。 真 PPO 中，单样本目标进入平台后，该样本在该方向的激励被截断；共享参数、其他样本梯度、动量或其他损失仍可让 ratio 越界。此演示只是假定概率按固定倍数增长，不模拟梯度优化。

顺带回答一个你可能正想问的问题:既然每步都重新采样,ratio 不就永远贴着 1,clip 岂不是从不出手? ——好问题,答案藏在工程细节里:采一批数据很贵,PPO 会在同一批数据上反复更新好几遍(练几个 epoch,把数据榨干)。 反复到后面,策略已经挪了,ratio 开始漂离 1——clip 就是在这时踩刹车的。 这也是第 5 课"数据过期"的工程版结局:过期的数据不扔,但用的时候看紧它。 (同一批数据可以进行多个 epoch 的更新；真实训练还需考虑采样、KL 与停止条件。)
