# VLA 双臂操作仿真研究

[English](README.en.md)

这是一个仍在推进的机器人学习项目：两台 Panda 机械臂需要开盖、清理障碍、抓起锤子、完成双臂交接，最后将物体放入指定箱子。研究重点是理解模型怎样从示范中学习，以及为什么动作预测误差变小后，机器人仍可能无法完成整个任务。

项目以 **π0.5 模型适配、BC-RNN 基线和闭环失败分析**为主线，使用 openpi、MuJoCo、robosuite、robomimic 与 DexMimicGen。

## 最新实验摘要（2026-10-30整理）

- 五路相机、200条示范、82,036帧；双臂控制与模型保存/重载流程已适配。
- 最新一轮60局开发评测：基线B0 **0/20**、均匀续训U **1/20**、阶段加权M **1/20**。已出现个别成功，但尚未证明稳定提升或阶段加权优势。
- 另一次全参数/LoRA对照为 **0/20 对1/20**，是独立实验，不与上述批次混合统计。
- Cosmos 3 Edge完成保持/左移/右移三组动作、两个配对种子的 **6段生成视频**与动作接口检查。未验证准确动作后果预测或闭环任务收益。
- 全部为仿真与模型推理研究；训练及GPU任务当前暂停。下方历史视频和结果保留原始条件与标签。

## 已完成的工作

- 整理 200 条训练示范、82,036 帧数据，按完整轨迹划分数据集，只用训练集计算归一化参数。
- 连接图像、18 维机器人状态与任务文字，生成未来 10 步、每步 14 维的双臂控制命令。这里的 14 维是控制器输入，不是 14 个物理关节角。
- 完成 π0.5 LoRA 适配与续训，比较均匀采样和抓取、交接阶段采样，保留实际样本曝光及模型恢复记录。
- 建立抓取、抬升、交接、入箱和整任务完成的分阶段评测；将专家先帮助一段再交给模型的实验，与从初态自主执行分开报告。
- 在有界开发实验中比较每执行 1 步或 5 步后重新观察。
- 完成五相机 BC-RNN 基线的固定 50,000 步训练，并开展预先指定的小样本开发诊断。
- 对照视频、夹爪命令、双指接触和物体运动，区分未抓稳、主动释放、闭夹状态下滑落和接收未对准。

## 当前结果

以下是历史开发诊断，不是正式泛化测试。逐回合摘录见 [结果文件](evidence/selected_results.json)。

| 模型 | 评测范围 | 原环境整任务成功 |
| --- | --- | ---: |
| π0.5 A，16,000 步 | 20 个开发初态，各执行 3 次 | 5/60 |
| π0.5 B，16,000 步 | 相同初态和执行安排 | 4/60 |
| π0.5 加权模型，11,000 步 | 相同初态和执行安排 | 2/60 |
| BC-RNN，固定 50,000 步 | 3 个预先指定的旧验证初态 | 0/3 |
| 同一个 BC-RNN 模型 | 3 个预先指定的训练初态 | 1/3 |

前三个模型的训练历史不同，不能仅凭此表判断某种采样策略的因果效果。BC 的训练初态成功案例在第 423 个控制步首次满足原环境成功条件；3 次开发执行也不足以证明稳定能力。

一个明确的观察是：**训练误差下降并不保证闭环任务完成**。单条示范续训的损失下降后，固定诊断仍未通过。不同回合的物理失败过程也不相同，不能把所有失败都解释成提前松手。

## 如何阅读与复现

`transport/openpi/` 包含适配、训练与闭环执行代码；`transport/day2/` 和 `transport/day3/training/` 包含阶段采样；`transport/day4/` 提供五相机和 BC-RNN 扩展；`evidence/` 与 `assets/` 保存精简结果和标注过来源的视频。

先阅读 [复现说明](docs/REPRODUCTION.md) 和 [第三方来源与许可证](THIRD_PARTY_NOTICES.md)。不需要 GPU、模型权重或任务数据，即可运行接口与记录逻辑的 CPU 合成检查：

```bash
python -m pip install -r requirements/review.txt
python transport/openpi/adapter_checks.py
python transport/openpi/pipeline_checks.py
python scripts/check_evidence.py
```

CPU 检查通过不等于机器人已经学会任务。完整训练需自行获取上游代码、数据和权重；公开包不承诺对历史所有运行逐位复现。

## 研究边界

目前结果来自仿真、单一任务指令和有限训练种子，不代表任意语言泛化、未知分布鲁棒性、真机部署或 Sim2Real。重复执行不等于多个独立训练种子；辅助接管与自主执行分开解释。

上游模型、算法、仿真平台和数据属于各自作者。本仓库主要展示任务适配和实验工具，不将 π0.5、BC-RNN 或仿真平台作为个人原创算法。仓库不包含模型权重、原始数据、云端认证文件或私人简历；第三方组件继续适用原许可证。
