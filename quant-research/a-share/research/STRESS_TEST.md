### 0.3 归因与可预知性的定义

- **事后归因**:逐日主动暴露(持仓 − 池等权)× 当日 Barra 纯因子收益,窗口内求和,拆成国家/风格/行业/特质/成本。
- **事前情景**:只用窗口开始前一天收盘时的实际持仓与暴露,乘以窗口内纯因子收益之和 = 预测主动收益。
- **事前风险**:因子协方差与特质方差只用决策时点已实现的 250 个交易日,报 z = 实际 / 预测跟踪误差。
- 判据:事前预测与实际同号且解释 ≥ 50% → "方向事前看得见";|z| > 2 → "幅度超出事前风险模型"。
- 脆弱性:W1 超额(pp)与以全期日超额标准差为单位的 W1 超额,两项同向才判谁更脆弱。
- 反事实:打分对 Barra Size 暴露逐日截面中性化后重跑;敏感性对 Size + NonlinSize + Liquidity 同时中性化。
  同时报全期、开发窗 2021-2023、检验窗 2024-2025 的年化超额代价。

## 1. 结论速览

**W1(2024-01-02 ~ 02-07,27 个交易日)亏了多少**(`stress_windows.csv`,超额 = 策略复利 − 池等权复利):

| 对象 | 窗口收益 | 超额 | σ 数 | 窗口内最大回撤 | 相对净值最大回撤 | 绝对净值恢复 | 相对净值恢复 | W1 起点到 W1b 终点相对净值 |

| 中证1000 | −18.50% | +9.92pp(对同钟池等权) | +5.23 | −27.08% | −2.10% | 157 日 | 17 日 | +4.64% |
| **COMP 排雷** | −25.40% | **+2.58pp** | **+3.62** | −30.67% | −0.17% | 155 日 | 0 日 | +3.01% |
| COMP Top20 | −33.13% | −5.15pp | −2.43 | −34.39% | −9.10% | 156 日 | 3 日 | +1.58% |

"W1 起点到 W1b 终点相对净值" = (1 + 策略复利)/(1 + 基准复利) − 1,窗口 2024-01-02 ~ 02-29(派生窗口,事后追加)。
† 池等权的窗口收益(−27.98%)与回撤是 open10 口径;它对中证1000 的比较用**同钟收盘口径**(同一个池按 te 收盘对收盘等权,W1 −28.43%),
因为 open10 收益覆盖 [te 开盘, te+1 开盘],与中证1000 的收盘价差半天。open10 池等权对中证1000 按 te / te+1 两种对齐,
W1 差距是 −9.48 ~ −13.26pp(`stress_csi_alignment.csv`,§7.3)。

四个问题的回答:

1. **排雷和选优谁更脆弱?选优。** 按预注册判据(pp 与 σ 数两项同向):排雷 +2.58pp / +3.62σ,
   选优 −5.15 ~ −13.42pp / −2.43 ~ −4.25σ。排雷在危机里不但没亏,反而是全样本最好的一段之一。
2. **亏损来自哪里?** 绝对亏损是市场的:池等权 W1 的 −31.22%(日收益之和)里风格占 −26.96pp,
   其中 **Size 一项 −19.35pp(池等权自身绝对亏损的 62%)**。相对池等权的亏损,选优组合**风格与特质大致各占一半**
   (`stress_attribution.csv`):风格 Top20 −4.89pp、Top50 −4.10pp、B_gbt −12.40pp,特质 −5.15 / −5.44 / −14.09pp。
   风格里的主角是 **Size + NonlinSize**(Top20 −9.11pp、Top50 −8.39pp、B_gbt −11.56pp);COMP Top-N 的这部分来自窗口内
   换进小票、恰好赶上 2 月初最大的几天下跌(§3.4),被盈利、低流动性、Beta 的约 +4pp 部分抵消。
   特质项做"同档池内平均"的匹配拆分(§3.3,`stress_specific_matched.csv`)后:
   - **B_gbt**:约一半(−6.35 ~ −8.21pp,随市值档从 5 档细到 100 档)是**微盘这一档整体**在 Barra 风格之外的额外下跌;
     另一半(−7.73 ~ −5.87pp)是**在微盘里选到的股票比同档平均还差**。
   - **COMP Top-N**:按市值匹配,档位效应几乎为零(−0.1 ~ −0.7pp),特质亏损不是微盘问题;向"过去 20 日跌最多"倾斜(接飞刀)
     解释 −1.7 ~ −2.3pp(约三到四成),其余 −2.9 ~ −3.6pp 是档内选股,本报告测过的维度解释不了。
   残差波动(ResidVol)不是主因,贡献绝对值都 ≤ 0.19pp。
3. **事前能看出来吗?** 用 Barra 暴露做情景分析(`stress_exante_vs_realized.csv`):**排雷看得见**(预测 +4.62pp,实际 +3.48pp);
   **选优看不见**——COMP Top20 窗口前暴露预测 +18.33pp,实际 −7.07pp,方向相反;B_gbt 预测 −1.57pp,实际 −19.50pp
   (同号但只解释 8%,按预注册判据仍是"看不见";其中风格一项预测 −10.81pp、实际 −12.40pp,是看得见的)。
   事前风险模型 z = −3.64 / −5.22 / −8.21,全部超出 2 倍预测跟踪误差;W1 的纯因子收益是 4.5~13σ 事件。
   **最朴素的持仓统计能看见 B_gbt 的微盘集中**:窗口前 93.4% 的持仓在全 A 市值最小 20%、97.4% 的持仓日均成交额
   不到 5000 万(`stress_liquidity.csv`)——这对应它风格亏损与特质亏损里"档位效应"的那部分;档内选股的那一半,任何事前统计都看不见。
   COMP Top-N 则是窗口内每周调仓把持仓换进了下跌的小票(Top20 微盘占比 6.8% → 最高 44.2%,`stress_holdings_path.csv`),
   这次换仓在新口径下就是它风格亏损(Size + NonlinSize −8.4 ~ −9.1pp)的来源,但解释不了特质亏损的主体。
4. **把 Size 约束到 0 能避免多少?**(`stress_counterfactual.csv`)预注册的打分中性化(N1)只少亏 0.62pp(Top20)/ 0.66pp(Top50)/
   3.97pp(B_gbt),原因是**打分中性 ≠ 组合中性**(N1 反而让 COMP Top-N 持仓更小)。
   事后追加的组合层市值中性(NS,分层选股)W1 少亏 8.94 / 8.80 / 17.24pp(三者 W1 超额都转正),但 W1b 反弹里少赚 9.48 / 8.77 / 14.65pp;
   全期代价 COMP Top-N 约为 0。**B_gbt 的样本外超额和小市值暴露绑在一起**,由预注册的 N1 支撑:检验窗每年少 11.69 ~ 17.75pp,
   t = −2.64 ~ −3.24,两种市值口径下都显著为负;事后追加的 NS 检验窗 −14.94 ~ −11.26pp/年(t = −2.01 ~ −1.14),方向相同。
   B_gbt 打分是旧市值训练的冻结打分,新口径下它的变体是"旧市值打分 × 新市值暴露 / 分档"的混合口径,
   所以只给区间(一端是旧市值下口径自洽的版本,另一端是新口径的混合口径;§8 第 4 条,`stress_mvfix_headlines.csv`)。
   NS 的 W1 数字对市值口径很敏感(旧口径少亏 4.32 / 4.85 / 9.08pp),只宜读方向。

> **样本属性提醒**:COMP_v5 成员在 2020-2025 内选出,COMP 系列全部数字是**信号样本内**,只测组合构建层;
> B_gbt 在 2023-2025 是 walk-forward 样本外。所有收益数字受幸存者偏差影响(§7)。

### 3.3 特质亏损从哪来:档位效应 vs 档内选股(`stress_specific_matched.csv`,W1;审查后重写)

第一版把特质贡献按持仓所在的桶加总("B_gbt 的 −17.13pp 来自全 A 最小 20%",旧市值口径;新口径该桶 −13.57pp),这是同义反复:
B_gbt 窗口内 99.75% 的已投资权重就在那一档,任何亏损都会落在那里(原始分桶数字仍在 `stress_specific_breakdown.csv`)。
要回答"是这一档整体跌了,还是在档里选错了股",需要**匹配拆分**:每只持仓的期望残差 = 当日池内同档股票的等权平均残差,

- 档位效应 = Σ 持仓 × 同档池内平均残差 − 已投资比例 × 池等权残差(持仓的档位分布能解释的部分);
- 档内选股 = Σ 持仓 ×(自身残差 − 同档池内平均残差)。

两者之和逐对象逐窗口等于特质合计(误差 < 1e-15),与归因长表的特质项相差 < 3e-8(`recon_err` 列,持仓以 float32 落盘)。桶越细,档位效应越接近"纯档位"能解释的上限。

读法:

- **B_gbt**:微盘这一档整体在 Barra 风格之外的额外下跌(档位效应)是 −6.4 ~ −8.2pp,约占特质亏损的 45% ~ 58%。
  这部分是风险模型的盲区:Barra Size 按 ±3σ 截尾、以市值加权均值为中心,**2023-12-29 池内 23.4% 的股票 Size 暴露都等于 −3**
  (`stress_barra_clip.csv`;各窗口前一日最高为 2024-09-23 的 34.0%),线性 Size 分不清"小盘"和"微盘"。
  新市值让截在 −3 的股票比例从 37.4% 降到 23.4%,原先落在特质里的一部分微盘下跌被 Size / NonlinSize 接走
  (B_gbt 风格 −8.38 → −12.40pp、特质 −17.84 → −14.09pp,见文末重跑记录),但档位效应占比基本不变。
  另外的 −5.9 ~ −7.7pp 是**在微盘里选到的股票比同档平均还差**:B_gbt 已投资部分的残差之和 −17.03%,池内微盘档平均只有 −7.95%。
  这一半既不是 Barra 风格,也不是"微盘"本身,本报告没有找到它的来源。
- **COMP Top-N**:按市值匹配,档位效应只有 −0.1 ~ −0.7pp——**它的特质亏损不是微盘问题**(它的小票问题在风格项里,§3.2)。
  按过去 20 日收益匹配,"向刚跌过的票倾斜"(接飞刀的档位部分)解释 −2.0 ~ −2.3pp(37% ~ 44%),再同时控制市值后
  −1.7 ~ −1.8pp(33% ~ 34%);其余 −2.9 ~ −3.6pp 是档内选股,本报告测过的维度(市值、过去 20 日收益、ST)都解释不了。
  第一版"COMP Top-N 是接飞刀"言过其实:接飞刀只解释约三到四成。

- ST 股在 W1 不是因素(Top20 的 ST 权重为 0)。

## 7. 幸存者偏差与其他偏差

**幸存者偏差**(`stress_survivorship.json`,由 `run_stress_test.py analyze` 生成,只用 `stock_basic.csv` 里退市日 ≤ 2025-12-31 的记录):

- 这些股票绝大多数是 ST / 面值退市 / 财务类退市的微盘股,2024 年初和"国九条"期间跌幅极大。

- 对**选优**:COMP 打分有反转成分,在危机里会买跌得多的票,有可能买到这些股票;缺失使选优的危机亏损
  **可能被低估**(结论不保守)。B_gbt 全仓微盘,受影响的方向相同。

1. **Barra Size 截尾**(`stress_barra_clip.csv`):池内被截在 −3 的比例在窗口前一日为 15.5%(W5,2022-02-28)、
   23.4%(W1)、31.4%(W1b)、30.5%(W2)、34.0%(W3)、29.4%(W4)。旧市值口径是 15.8% ~ 54.1% 且逐年上升;

   (按新口径池内市值五分位,旧 / 新之比的均值 W1 是 Q1 1.30、Q5 1.48,W4 是 Q1 1.44、Q5 1.54;各档中位数都约 1.00),

读法:

1. **打分中性 ≠ 组合中性。** 预注册的 N1 让 COMP Top20 的 Barra Size 归一化暴露从 −0.08 变成 −0.37、
   池内市值秩从 0.466 降到 0.337——持仓**更小**了,因为 COMP 打分的头部本来略偏大盘,线性去掉 Size 后头部被小票占据。
   N3 让三个选优组合的 Liquidity 归一化暴露从 −0.59 ~ −0.69 翻到 **+1.10 ~ +1.24**(去掉线性关系后,打分残差的头部被高换手股票占据)。
   **线性中性化打分控制不住 Top-N 这种只取尾部的组合的暴露**——要约束暴露,必须在组合层做(分层选股或优化器约束)。
2. **N3 的 W1 符号对市值口径不稳**:新口径下 N3 在 W1 少亏 2.09 / 2.24 / 9.30pp,旧口径是多亏 2.80 / 2.57 / 0.69pp;
   W1b 则少赚 6.40 / 2.87 / 12.59pp。COMP Top20 N3 的 W1 拆解是 Liquidity −8.44pp、特质 +3.79pp(`stress_attribution.csv`),
   即高换手倾斜照样挨打,少亏来自换进的具体股票。同一个预注册方法、只换市值就翻号,说明 N3 的危机表现不是稳定性质,只能读成"没有稳定的保护"。
   (COMP Top20 / Top50 的打分不用市值,翻号是纯市值口径效应;B_gbt 的 −0.69 → +9.30pp 是混合口径,见第 4 条。)
3. **真正把 Size 压到 0 的 NS**:COMP Top-N 在 W1 少亏 8.94 / 8.80pp(把 −5.15 / −7.02 变成 +3.79 / +1.77),
   但 W1b 少赚 9.48 / 8.77pp;从 W1 开始累计到 2024-03-29,COMP Top20 NS +7.42% vs 原始 +3.54%,
   COMP Top50 NS +5.46% vs 原始 +0.88%(`stress_fig_tail_values.csv`)。W1 对 COMP Top20 是 3 日就收复的 V 形、
   对 Top50 是 25 日收复(§2.1),约束 Size 主要是把这个坑抹平;全期代价约为 0(|t| ≤ 0.26),开发窗与检验窗都不显著:
   **NS 对 COMP Top-N 是"降波动、不改收益"**。
   NS 在 W1 少亏的部分**主要来自风格项**:COMP Top20 的 W1 日主动收益之和从 −7.07 变成 +5.15pp,其中 Size + NonlinSize 从 −9.11 变成 −0.20pp,
   特质只从 −5.15 变成 −3.62pp(Top50 同样:Size + NonlinSize −8.39 → +0.05pp,特质 −5.44 → −3.29pp)。
   这与 §3.2"COMP Top-N 的风格亏损来自窗口内换进小票"一致:分层选股不让它在危机里集中换进小票。
   (原文写"NS 少亏的部分不是消除市值档位效应,而是档内选股那一块",这一读法在旧口径账本里也不成立——
   旧口径 NS 的 W1 改善同样有 5.28pp 在风格、只有 0.98pp 在特质——此次更正。)
   **NS 的 W1 数字对市值口径很敏感**:同一方法旧口径只少亏 4.32 / 4.85pp,只宜读方向。
4. **B_gbt 的超额和小市值暴露绑在一起,证据来自预注册的 N1**:新口径下 N1 检验窗年化 −17.75pp(t = −3.24)、全期 −10.59pp(t = −2.59);
   N1r 检验窗 −21.71pp(t = −2.06)。事后追加的 NS 在 W1 少亏 17.24pp(W1 超额 −13.42 → +3.82pp),
   但检验窗年化 −11.26pp(t = −1.14)、全期 −9.11pp(t = −1.35)(旧口径 −14.94pp,t = −2.01)。
   **口径提醒(审查后补)**:B_gbt 打分是旧市值训练的冻结打分(特征 `nd_mv`,§7 第 7 条)。新口径下 N1 是拿它对新市值的 Barra Size 中性化、
   NS 是按新市值五分位分层,残差打分里还带着新旧市值之差(解禁造成的市值扭曲),所以上面这些数与旧口径之间的差**不全是市值修复的效应**。
   口径自洽的版本只有旧市值下的"旧打分 × 旧 Size":N1 检验窗 −11.69pp(t = −2.64)、全期 −6.72pp(t = −2.02),
   NS 检验窗 −14.94pp(t = −2.01)、全期 −10.96pp(t = −2.13),N1r 检验窗 −21.80pp(t = −2.08)
   (原报告账本 `_pre_mvfix/stress_counterfactual.csv`;旧口径影子重跑 N1 −11.69pp、t = −2.63,`stress_mvfix_headlines.csv`)。
   稳健的读法是区间:**预注册 N1 检验窗 −11.69 ~ −17.75pp/年(t = −2.64 ~ −3.24),两个口径都显著为负**,结论方向成立、幅度不确定;
   NS 检验窗 −14.94 ~ −11.26pp/年(t = −2.01 ~ −1.14),方向相同,"不显著"只在混合口径下出现,不能当作市值修复本身的结论;
   N1r 两个口径几乎相同(−21.80 / −21.71pp)。
   B_gbt 的 walk-forward 超额相当一部分是小市值溢价,去掉小市值暴露就大幅缩水。**要 B_gbt 的超额,就得接受 W1 这种 −13pp、
   相对净值 141 个交易日才收复的窗口**。
5. **排雷不需要这个约束**:N1 / N1r / NS 对排雷的 W1 影响都 ≤ 0.21pp,N3 为 −1.26pp。
   N3 对排雷的全期代价 −1.74pp/年(t = −2.08)在新口径下越过了 2(旧口径 −1.57pp,t = −1.84)。
6. **N1 / N1r 让 COMP Top-N 全期多赚 4~7pp/年** 是附带发现,但它来自加大小票倾斜而非风险控制,
   检验窗 t = 1.65 / 1.40 / 1.54 / 0.98,全部 < 2,且 COMP 是信号样本内——**仅样本内,不构成正向结论**。

### 结论是否变化

**不变的:**
1. 预注册的脆弱性判据:排雷 +2.58pp / +3.62σ,选优 −5.15 ~ −13.42pp / −2.43 ~ −4.25σ,"选优更脆弱"。窗口收益、超额、σ、回撤、恢复天数、
   W1+W1b 相对净值全部逐位不变(§1 表、§2)。
2. 事前可见性的预注册判定:排雷"看得见"、三个选优"看不见",全部 |z| > 2;W3 急涨亏损事前可算。
3. B_gbt 的特质亏损约一半是微盘档整体下跌(45% ~ 58%,旧 42% ~ 60%);COMP Top-N 的特质亏损与市值档无关,接飞刀只解释三到四成。
4. 流动性锁仓不是 W1 亏损机制(§5)、维度层面"排雷更不脆弱"不成立(§6)、NS 对 COMP Top-N 是"降波动、不改收益"(全期 |t| ≤ 0.26)。

**变了的(正文已改):**
1. **"选优的亏损主要不在 Barra 风格里,而在特质项"不再成立。** 新市值让 Size / NonlinSize 更准地刻画小票(截在 −3 的比例 37.4% → 23.4%),
   原先落在特质里的小票下跌被 Size / NonlinSize 接走:COMP Top20 风格 −0.82 → −4.89pp、特质 −9.34 → −5.15pp;Top50 −0.85 → −4.10 / −8.77 → −5.44;
   B_gbt −8.38 → −12.40 / −17.84 → −14.09。现在是**风格与特质大致各半**,风格里的 Size + NonlinSize 是 −8.4 ~ −11.6pp
   (§1 第 2 问、§3.2、§3.4、§4.1、§12)。COMP Top-N 的风格亏损来自危机中换进小票的时点(Top20 微盘权重峰值 31.7% → 44.2%)。
2. **池等权绝对亏损里 Size 的份额 52% → 62%**(§1、§3.1、§12);W1 纯因子冲击 "5~10σ" → "4.5~13σ"(NonlinSize z 12.91)。
3. **B_gbt 事前总预测由 +2.18 变为 −1.57pp**,与实际同号但只解释 8%,判定仍为"看不见";风格预测 −10.81pp 对实际 −12.40pp 更贴近(§4.1)。
   COMP Top50 的 W3 z 变为 −2.25,新口径下也超出 2 倍预测跟踪误差(§4.3)。
4. **反事实大幅变化,且对市值口径敏感**(§8):
   - 预注册敏感性 N3 的 W1 效果翻号:旧口径多亏 2.80 / 2.57 / 0.69pp,新口径少亏 2.09 / 2.24 / 9.30pp;正文改为"N3 的危机表现不稳定"。
     (COMP 两个是纯市值口径效应;B_gbt 是混合口径,见下一条。)
   - 事后追加的 NS 在 W1 少亏 4.32 / 4.85 / 9.08 → 8.94 / 8.80 / 17.24pp(三者 W1 超额都转正),W1b 少赚也同步放大到 9.48 / 8.77 / 14.65pp。
   - **B_gbt"约束 Size 要付出检验窗每年约 15pp(t = −2.01)"改写为区间**:B_gbt 打分是旧市值训练的冻结打分,新口径下它的变体是
     "旧市值打分 × 新市值暴露 / 分档"的混合口径,旧 → 新的幅度变化不全是市值修复的效应(审查处理第 2 条)。
     预注册 N1 检验窗 −11.69pp(t = −2.64,旧市值自洽)~ −17.75pp(t = −3.24,新口径混合),两端都显著为负;
     事后 NS 检验窗 −14.94pp(t = −2.01)~ −11.26pp(t = −1.14),方向相同,"不显著"只出现在混合口径下。
     "B_gbt 的样本外超额与小市值暴露绑在一起"保留(方向在两个口径下都成立),主要证据是预注册的 N1,幅度只给区间(§1 第 4 问、§7 第 7 条、§8 第 4 条、§12)。
   - 排雷 N3 的全期代价 t 从 −1.84 变为 −2.08。
5. **截尾诊断**:池内截在 −3 的比例 15.8% ~ 54.1% 且逐年上升 → 15.5% ~ 34.0%,2024 年后约三成、不再单调(§7 第 1 条)。
   机制是旧口径对大票高估更多、把 Size 的市值加权零点右推(gap 从 2022-02 的 2.07σ 升到 2025-04 的 2.88σ);修复后 gap 为 2.05 ~ 2.45σ
   (`stress_mvfix_clip_mechanism.csv`)。不是"池内市值分布更分散"——池内标准差反而略收窄。

**顺带更正(旧口径下就不成立,与市值修复无关):**
1. §8 原文"NS 在 W1 少亏的部分不是消除市值档位效应,而是档内选股那一块":旧口径账本里 NS 对 COMP Top20 的 W1 改善已有 5.28pp 在风格、
   只有 0.98pp 在特质;新口径下风格 +10.59pp、特质 +1.52pp(`stress_attribution.csv` COMP_TOP20|NS − COMP_TOP20,W1)。已改为"主要来自风格项"。

3. §3.3 / §10 的对账误差写法:匹配拆分两部分之和与特质合计的误差 < 1e-15,与归因长表相差 < 3e-8(原文把后者写成 < 1e-9);分桶加总 < 6e-8。

**未重跑 / 留给后续:** B_gbt 打分未用新市值重训(因此它的四个反事实变体是混合口径,§7 第 7 条);BookToPrice / EarningsYield 分母仍是近似市值(§7 第 7、8 条)。
