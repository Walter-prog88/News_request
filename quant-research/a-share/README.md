# A 股分钟量价因子与组合研究

围绕 A 股分钟量价数据，研究因子如何形成截面信号，以及信号经过交易成本、风险约束和执行规则后还能保留多少收益。代码覆盖数据聚合、因子构建与评价、模型比较、风险归因、组合优化和检验工具。快照日期：**2026 年 10 月 30 日**。

## 目录与核心实现

| 目录或文件 | 内容 |
| --- | --- |
| `src/afactor/` | 面板、因子、截面模型、回测引擎、成本模型、风险模型、优化器及研究接口 |
| `scripts/` | 数据准备、因子与模型实验、成本／容量、风险／压力、前向数据检查及增量研究脚本 |
| `tests/` | 引擎、数据截止时点、风险、优化器及增量研究的测试源码 |

## 主要研究过程

- 将分钟量价数据聚合为日频研究面板，构建千余种候选因子，使用 Rank IC、分层、相关性和滚动检验评价信号。
- 比较线性组合与 GBDT 截面模型，检查样本划分、调仓相位、特征选择及反复试验对结论的影响。
- 将佣金、印花税、价差、冲击成本、成交参与率和不可成交规则接入回测，研究成本、容量与组合集中度的关系。
- 实现行业／风格风险归因与组合约束，分析因子收益来自选股还是流动性等风格暴露。
- 保留不成立的方向和口径修正，使用数据时点检查、配对比较和静态冻结记录约束事后解释。

## 结果应如何理解

- **低换手风险排除组合主要体现流动性风格暴露。** 风格剥离后没有显著正的残差收益，不能包装成稳定的独立选股能力。
- **集中选股结果对真实成本高度敏感。** 在统一基准和千万资金情景下，加入价差与平方根冲击后，原先漂亮的集中 GBDT 回测结果转为负超额。成本系数来自文献情景，未用真实成交校准。
- **执行与过滤增量仍需谨慎验证。** 部分历史规则有小幅模型内增量，但样本独立性、事件日期可知性和真实订单执行仍存在边界。
- 研究面板缺部分退市股票；历史代理指数、风险预测和短验证窗口均有局限。不同窗口、基准和算术／几何口径的数值不能直接拼接或相加。

## 复现前提

1. 自备有使用权限的分钟行情及所用日频／财务／事件数据，依照各脚本的数据字段与截止时点要求整理。
2. 主要依赖 Python、NumPy、Pandas、SciPy、Scikit-learn、PyArrow；风险、优化、画图或取数脚本另有各自依赖。公开包没有重建或验证一份覆盖全部历史实验的统一锁定环境。
3. 从本目录运行脚本，并根据实际数据位置检查配置和历史路径。部分跨项目研究接口还依赖未随包分发的数据层。
4. `tests/` 保留研究测试源码；依赖真实面板、历史金标准或外部数据的测试，需要自行准备对应输入。它们不等于一键运行即可获得所有历史结果。

本次只做源码导出、结果范围筛选和 Python AST 检查，没有执行研究计算。完整数据、逐标的收益与持仓、完整试验账本及大型报告副本未分发。
