# Zoo v1 — 机械网格 + 滚动选择函数(协议冻结 2026-08-15)

## 目标
在不引入外部数据的前提下,对全部本地信息源做机械化宽搜索,
用**因果滚动选择函数**把探索/利用合法化,交付一条可审计的组合曲线。

## 三条红线(不可修改)
1. **因果性**:任何信号在 t 日只能使用 t 日 15:00 之前可知的数据。
2. **分类不从收益推导**:分组只用 `symbol_master`(产品元数据)。
3. **截面模块必须多空**;只做多仅允许出现在配置层(sleeve)。

## 数据封存
- `SEAL = 2026-05-21`。所有搜索代码默认读不到这之后的数据
  (harness 强制截断;解封需显式 `ZOO_UNSEAL=1`,全项目只允许用一次,
  用于最终冒烟测试 2026-05-22 → 2026-07-24)。
- 2024-01-02 → 2026-05-21:已被历史研究污染(69 次候选选择)。
  **永不作为入围判据**;在滚动选择框架下仅作为"利用"阶段的行情输入。

## 试验账本
- 每次 `evaluate()` 自动追加 `trial_ledger.jsonl` 一行(spec哈希、窗口成绩)。
- 账本是事后去偏(deflated Sharpe)的分母,**不许删除或绕过**。

## 滚动选择函数(元参数事先冻结)
- 每 5 个交易日,用截至当日的各模块净值选模块。
- 入选:trailing Sharpe(窗口 W)> 阈值 θ;与已选模块 trailing 相关 |ρ|<0.85。
- 权重:入选者按逆波动率,单模块上限 25%;模块切换额外收 10bp。
- 元参数网格只有 4 个变体:W∈{126,252} × θ∈{0.0,0.3}。
  **主变体 = (252, 0.3),现在指定,不得事后改。** 其余 3 个作为敏感性一并报告。

## 成本与执行约定
- 截面腿:10bp/往返 × 换手;信号 t → 收益 t+1(收盘成交近似);
  H 日持有用 H 个重叠分批,收益记在兑现日。
- 配置层同样 10bp × 换手。

## 退出条件(先到先停)
1. 主变体组合达标(Sharpe≥1.5 且 Calmar≥1.5,含去偏检验)→ 交付;
2. 连续 3 条信息源轴产出 0 个合格模块 → 停止,交付诚实最大值与缺口;
3. 试验总数 2000 → 强制停止。
