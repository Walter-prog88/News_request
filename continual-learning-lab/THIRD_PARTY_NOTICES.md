# 第三方来源与公开范围

本项目保留作者工作区中的教学实现、实验脚本和已生成结果。代码编写与整理使用 AI 编程工具。研究算法和论文结论归原作者；请引用原始研究，不能把本仓库包装成这些算法的原创实现者或论文级复现认证。

- 上游 `shibhansh/loss-of-plasticity` 的 Git 克隆、其 `lop/` 包和仓库历史没有随本项目分发。本项目的自包含小脚本用于教学研究，已在源码说明简化之处。
- scikit-learn、PyTorch、NumPy、matplotlib 由用户单独安装，各自适用其原许可。
- `scripts/prepare_digits.py` 调用 scikit-learn 的 `load_digits` 并归一化数据。原始数字数据、导出 NPZ、模型权重均未随包上传。数据归属和使用条件以该工具和数据源的说明为准。
- 结果 CSV 和 PNG 是本地已完成小规模实验的产物。公开整理时从原 CSV 重新生成汇总图表，没有重新启动训练。未完成的配置不填补、不插值成已完成结果。
- `02` 的主扫描和调参未完成，`04` 只有一个种子的部分配置。`05` 的学习率选择使用该实验的任务表现，属于探索性比较；不是独立盲测。
- `06` 的诊断仅支持该小 MLP 设置中的现象关联。尚未完成消融来证明唯一因果机制，也未验证修复方法或机器人迁移效果。

项目不包含用户账号、私人研究对话、原始金融/公司数据、模型检查点、训练环境、API 凭据或私人绝对路径。未为任何第三方内容另行授予许可。
