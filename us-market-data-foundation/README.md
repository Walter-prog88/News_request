# SEC 财务数据层与安全数据湖

把公司财务披露整理成保留来源、修订版本和缺失状态的研究数据。这是本地美股数据底座的**精选公开模块**，适合学习财务标准化、数据质量检查和可追溯查询。

本公开版保留 13 个 Python 模块、10 个测试文件、财务字段与因子定义，以及一个纯合成的离线例子。代码开发和公开整理使用了 AI 编程工具；功能与结果以源码和可运行测试为准。

## 能做什么

- **保留披露版本**：同一经济期间的原始申报、比较数字和修订分别保存；不把财报的 `fy/fp` 直接当作每个数字所属期间。
- **区分财务期间与口径**：区分资产负债表时点值、直接季度、累计半年/九个月和年度流量；有条件地计算季度差额，并保留输入披露和兼容性标记。
- **检查数据质量**：检验会计勾稽、缺失、冲突、非有限值及不合理日期；问题版本不会被悄悄删除后用旧值补成“最新值”。
- **按日级信息截止查询**：保留来源、币种、标签与法律实体。保守日期估计不代表精确的首次公开时刻，接口明确拒绝严格盘中 PIT 声明。
- **构建研究面板与因子**：公司样本选择、缺失覆盖率、源口径一致的行业样本汇总，以及基于明确输入定义的利润率、现金流等指标。样本汇总不代表 GDP 或完整行业。
- **控制数据写入**：数据湖提供原子发布、预算、路径与软链接检查、读写锁；macOS 外盘检查在卷身份不符时停止。
- **提供受限 SEC 传输组件**：保存原始响应哈希与历史申报列，限制重试、响应大小与请求频率；离线示例和测试不访问网络。

## 五分钟离线示例

要求 Python 3.11 或以上。在项目目录执行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
PYTHONPATH=src .venv/bin/python examples/synthetic_financials.py
PYTHONPATH=src .venv/bin/python scripts/verify_offline.py
```

示例构造一家不存在的公司的两次收入披露：原报 100，后续修订为 110。按早期截止日查询仍得到 100；按更晚截止日查询得到 110。数据由脚本生成，不需要数据库、API key、外盘、行情订阅或下载原始财报。

`verify_offline.py` 运行本包测试并禁止建立网络连接。它只使用合成数据、模拟响应和临时目录；不采集真实数据，不连接实际数据湖。验证范围见 [VALIDATION.md](VALIDATION.md)。

## 接真实数据前

公开版没有生产股票池、数据库、外部网页副本、历史行情、研究报告或个人配置。原工程的完整采集编排、宏观库和仪表盘也不在此精选版内，不能从本包推断其数据覆盖率或策略表现。

如使用 `SecClient`，先通过环境变量 `SEC_USER_AGENT` 配置符合 SEC 要求、包含自己联系信息的标识，并自行确认访问规则。不要把凭据写进代码或提交到 Git。

如使用实际 `Lake`，需要自行提供 `config/storage.json` 和已有外盘中的身份标记。参考 `config/storage.example.json`；示例占位值不能直接用于实际写入。此实现的外盘检查依赖 macOS 的 `diskutil`，文件锁依赖 POSIX；离线测试通过模拟系统调用检验这些边界，未验证其他系统上的实际磁盘行为。

## 来源与适用范围

SEC/XBRL 标签和公开接口属于上游数据体系。Python 依赖各自遵守其许可证；本包不重新分发原始公司文件、供应商数据、第三方数据库或学术数据集。详见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

这里展示数据工程与研究方法，没有收益承诺。离线合成测试通过只说明所覆盖的行为符合断言，不证明任意公司、会计体系或数据供应商都能无误处理。
