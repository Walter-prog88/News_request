# 量化因子算子与模拟演示

本目录精选原量化项目的截面与时间序列算子，用模拟数据展示因子处理方法，不附真实行情、持仓或策略收益。

## 内容

- `factor_ops.py`：截面排名、标准化、去极值、中性化，以及滚动均值、延迟等时间序列操作；依赖 NumPy／pandas。
- `synthetic_demo.py`：固定种子生成 40×50 模拟矩阵，串联延迟、滚动处理、排名与单因子暴露中性化。
- `test_factor_ops.py`：检查中性化残差均值与暴露、未来值扰动不影响历史前缀，以及常数截面保持不可用状态。

依赖原项目未打包模块的市值／行业联合中性化辅助函数已省略。这一目录不构成完整回测系统，模拟输出不用于估计投资收益。

## 轻量演示与检查

以下命令从上一级 `methods/` 目录执行，不加载市场数据，也不回测策略：

```bash
python quant/synthetic_demo.py
python -m unittest discover -s quant -p 'test_factor_ops.py' -v
```

历史检查记录为：3 项单元测试通过；模拟演示有 1,900 个有效输出，中性化残差与暴露的最大内积绝对值为 1.22e-15。它反映这个模拟输入上的数值性质，不代表策略收益或预测能力。本次中文说明维护没有重新运行检查。
