# 小模型 LoRA 与持续学习实验

## 数据与划分

两个实验均使用 scikit-learn 自带的 8×8 手写数字数据：1,797 个样本、64 维特征、10 个类别。像素除以 16 并转换为 float32，标签为 int64。每个随机种子通过 PyTorch 生成固定排列，前 360 个样本用于测试，其余 1,437 个用于训练。`load_digits` 从已安装的 scikit-learn 本地加载，本目录不打包数据集。

## 实验 05：全参数更新与 LoRA

MLP 结构为 64→100→100→10，隐藏层使用 ReLU。预训练采用 SGD，学习率 0.05，训练 30 个 epoch。新任务分别为图像水平翻转与固定种子的像素重排。比较全参数更新以及秩 1／2／4／8／32 的 LoRA，每组使用 5 个种子、适应训练 40 个 epoch。全参数学习率为 0.003／0.01／0.03，LoRA 学习率为 0.03／0.1／0.3，batch size 为 16。实际实现**直接使用 alpha = 1**，没有采用 alpha/r 缩放。

[原始历史指标 CSV](05_lora_forgetting/results/lora_vs_full.csv) 与[历史汇总表](05_lora_forgetting/results/summary.md) 保持原样。每种方法展示的学习率，按任务 B 最终测试准确率最高者选择，因此存在测试集选参偏差，属于探索结果，并非无偏的留出评估，也不能证明 LoRA 普遍学得更少或忘得更少。

例如，存档中的水平翻转任务：秩 8 LoRA 的任务 B 准确率为 96.4%，任务 A 保留准确率为 43.2%；全参数更新对应为 96.9% 与 63.7%。该任务和配置下没有观察到 LoRA 的旧任务保留优势。

## 实验 06：连续任务适应

相同的预训练 MLP 连续学习 300 个固定种子的像素重排任务，每个任务训练 3 个 epoch。比较全参数更新、重复使用同一 LoRA、合并后重置 LoRA，以及固定原主干并为每个任务更换新适配器。默认全参数学习率为 0.03，LoRA 为 0.1。历史汇总中秩 8 使用 5 个种子，秩 2／32 使用 3 个种子。表中 ± 为最后 50 个任务平均值在不同种子间的标准误，沿用原汇总脚本的计算方式。

本目录仅保留[实验 06 历史汇总表](06_continual_lora/results/summary.md)，未附各任务原始 CSV，因此不能仅凭这个精选包独立重新聚合该表。秩 8 的新适配器在最后 50 个任务上的当前任务准确率为 91.3% ± 0.6%，重复使用同一适配器为 49.4% ± 6.1%。但新适配器会丢弃此前任务的适应结果，不能把这一差值理解为无需代价的累积知识提升。

这些实验与机器人实验的协议不同，不能当作 VLA 成功率指标。方法比较属于探索性质；归档时，公平超参数调优和拟议修复实验尚未全部完成。

## 后续可选训练

只有显式提供训练开关才会训练。制作展示包与本次中文文档维护均**没有运行训练**。以下命令从上一级 `methods/` 目录执行：

```bash
python learning/05_lora_forgetting/lora_vs_full.py --run-training
python learning/06_continual_lora/continual_lora.py --run-training --method lora --rank 8 --seed 0
```

新结果写入各实验的 `runs/` 目录。实验 05 的历史汇总可通过 `summarize.py` 重新生成，需要 matplotlib；该脚本本身不启动训练。神经网络接口测试不执行优化器更新。
