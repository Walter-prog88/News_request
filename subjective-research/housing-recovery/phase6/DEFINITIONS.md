# 阶段六 操作定义：假设裁决与情景（所有智能体必须遵守）

用户确认：阶段五已确认（2026-09-09）。阶段六是 SPEC 的最后一个阶段。
SPEC 原文：「先逐条裁决 H1–H4：支持 / 部分支持 / 推翻，附证据。再给 2–3 个情景，每个情景明确其关键假设变量（开发商信用出清速度、名义增长/通缩路径、一线迁入政策、产业引擎强度），分别对应『美国式传导恢复』、『东京式下台阶』，以及如 H4 被推翻则补充『第三种路径』。不给单一年数。」

## 0. 硬约束（违反即判该产出无效）
1. **不给单一年数**。任何情景都不得出现「中国需要 X 年恢复」「预计 20XX 年回前高」这类表述，也不得用区间伪装（如「15–20 年」）。情景只描述**条件 → 路径形态**，路径形态用「已发生的日美 episode 作参照点」表达。
2. 裁决只能基于阶段一至五已落盘的数据。**不得新取数**（唯一例外：核实某条证据的原始出处时可 WebFetch 打开已记录的 URL）。每条裁决的每个证据必须给出「阶段 + 文件 + 具体数值」的可追溯引用。
3. H1 **不拆分**（用户 2026-09-09 决定）。保持 SPEC 原表述作为一条假设裁决，但理由必须分两层写：处置通道与货币通道分别评估，并给出修正版表述。
4. 裁决三档只能是 支持 / 部分支持 / 推翻。**不得用「无法判定」逃避**；若证据不足以裁决，写「部分支持」并在理由首句写明「证据不足以区分 X 与 Y」。
5. 小样本纪律沿用：n<6 不报 p 值；三种标准误不一致时以不显著对待；秩相关 n≤6 只作方向描述。

## 1. 裁决的证据基础（每条假设的指定输入）
- **H1 政策时滞**：phase3/output/table_B_lags.csv（两个时滞×11 个历史城市行）、table_D_relation.md（秩相关全口径）、table_E_japan_lost_decade.md（1992–2001 名义增长为正 6 年 / 房价上涨 0 年）、phase3 复盘 §7.2。必须同时评估：处置通道（ρ=+0.70, n=5）与货币通道（ρ=−0.09, n=6；日本宽松 14 月 < 美国 19–21 月）。
- **H2 名义增长**：phase2/output/table_C_h2.csv（三档自变量各窗口 R² 与 β）、findings_digest_phase2 §2、phase3 table_E（实际利率两版：CPI 版 2/10 年为负，平减版 0/10 年为负）。裁决标准按 phase2 复盘 §8.3-4 的修订：在 n≥8 的窗口里名义档 R² 高于实际档的比例是否过半，并报告两档 β 是否都显著。**不得沿用「显著高于」这一在现有样本上永远不可能达成的原标准，但必须说明标准被修订及理由。**
- **H3 城市增长引擎**：phase2/output/table_E_h3.csv、phase1 关于 Case-Shiller SF 不含 Santa Clara 的口径限制、phase2 §5（三维度结论不一致：恢复时长一致 / 恢复后 CAGR 相反 / 恢复后 β 不可分辨）、纽约公寓 ② 8.0 年 < 旧金山独栋 9.7 年 的房型混淆。**必须分维度裁决，不得给整体判决。**
- **H4 中间态**：phase2/output/table_F_cn_state.csv（14 个状态变量的区间内/外）、phase3 table_C_subject（信用主体类型）、phase4 §4（bust 与 25–39 岁人口见顶的相对时序）、phase3 §1（处置三判据未启动）、phase5（外资净卖出 + 接盘方为中资险资）。**SPEC 明确要求对 H4 保持开放、允许「第三种路径」结论。**

## 2. 裁决产出格式（每条假设一节）
- `verdict`：支持 / 部分支持 / 推翻
- `evidence_for`：逐条，每条含 数值 + 阶段 + 文件 + 该证据的强度（强/中/弱）与理由
- `evidence_against`：同上
- `preregistered_refutation_triggered`：SPEC 为该假设写的推翻条件是否被触发（是/否/部分），附证据
- `revised_statement`：若裁决非「支持」，给出数据支持的修正版表述（一句话）
- `what_would_change_it`：需要什么新证据才会改变这个裁决（可操作，如「再多 3 个 episode」「中国触底后 5 年的数据」）
- `caveats`：样本量、口径、可比性限制

## 3. 情景的构造规则
- **关键假设变量（SPEC 指定四个，必须全部出现在每个情景中）**：
  (a) 开发商信用出清速度 —— 用 phase3 的三判据（公共资金注资/收购不良、官方处置目标设定并达成、不良率见顶回落至峰值一半）表述，取值：未启动 / 已启动未达成 / 已达成
  (b) 名义增长与通缩路径 —— 用 名义 GDP 增速 与 GDP 平减指数 表述（中国 2023–2025 平减指数 −0.51/−0.76/−0.92%），取值：转正 / 零附近 / 持续为负
  (c) 一线迁入政策 —— 用 phase4 的三情景（维持 / 减半 / 归零）表述，并引用其对 25–39 岁人口 2035 与 2050 比例的影响
  (d) 产业引擎强度 —— 用 H3 裁决后可用的维度表述（恢复时长维度），并说明该维度在中国样本上只能作状态对照
- **每个情景必须写明**：四个变量各取什么值；对应哪个（或哪些）已发生的日美 episode 作参照；该 episode 的 ①②③ 实际用时（作为参照点而非预测）；该情景下**哪些阶段一至五的观测量会先变化**（可证伪的前瞻指标）。
- **情景数量**：2–3 个。若 H4 被推翻，必须包含「第三种路径」。
- **禁止**：给中国的年数、给概率权重（除非明确标注为主观且说明依据）、把情景写成预测。

## 4. 前瞻指标表（情景的可证伪性）
每个情景给 3–5 个**可观测、有数据源、有明确阈值**的前瞻指标，格式：指标名 / 当前值（引用阶段一至五）/ 该情景下预期的变化方向与阈值 / 数据源与更新频率。
例：「商业银行房地产业不良率」当前值来自 phase3/data/cn_re_sector_npl.csv，阈值「见顶回落至峰值一半」，来源 金融监管总局 季度。
