# 房地产信用出清后的恢复路径：中美日比较研究样本

这份研究从一个带判断的问题出发：房地产信用危机之后，核心城市的房价能否恢复，经济增长又能否重新传导到房产回报？它保留了事前假设、支持与反对证据、被推翻的判断和条件情景，适合参考研究问题的拆解与修正过程。

**原研究完成于 2026-09-09；2026-10-30 整理为公开样本，未更新数据。** “当前”“尚未启动”等措辞均指原研究日期，受原操作定义约束。研究通过 AI 辅助调研、编程与多轮复核完成，个人贡献包括问题选择、研究框架与判断的组织；不将其表述为全部由个人独立手工采集与推导。

## 原研究的判断

| 问题 | 历史稿的判断与反证 |
| --- | --- |
| 政策处置更早是否意味着恢复更快 | 原 H1 被推翻。货币宽松与资产处置是不同通道；跨国相关关系与国别混在一起，不能当作因果机制 |
| 名义增长是否比实际增长更重要 | 原 H2 为部分支持。去重后 45 格中 31 格的名义 GDP 回归 R² 更高；这是相关性的描述计数，显著格数尚未统一复核 |
| 科技城市是否恢复得更好 | 需拆成恢复用时、恢复后增速与传导系数。起点不同会机械影响年化增速；房型差异也可能与城市差异混淆 |
| 中国是否位于日本与美国之间 | 原 H4 被推翻。按所选样本与操作定义，信用主体、名义增长构成、租金收益率与处置状态并非简单插值；这不能证明未来必然走某一条路径 |

这些判断依赖样本和定义。研究没有给出中国恢复所需的具体年数，也没有给情景分配经过验证的概率。

## 可以复算的部分

```sh
python3 phase6/scripts/p6_h2_recount.py
```

只需要 Python 3 标准库。脚本从所附回归汇总 CSV 读取结果，按国家、episode、单位和窗口去重，每格优先总回报口径，再筛选名义与实际 GDP 两档样本数均不少于 8 的格，得到：

- 去重后共 75 格，合格 45 格；
- 名义 R² 更高 31 格，相同 2 格，实际 R² 更高 12 格；
- 31/45 = 68.9%。

这是聚合结果的计数复算，未重新取得价格、租金或宏观序列，也未重跑回归。45 格共享国家、城市和危机时期，不能当作 45 个独立实验。
