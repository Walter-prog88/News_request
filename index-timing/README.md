# 指数择时研究的数据层与方法记录

本目录公开已有指数／ETF研究中的数据接口实现、快照校验工具、测试源码和方法记录。它从原私人续建仓库中独立导出，**没有包含课程接口的原始响应、标准化行情／宏观数据、请求回执或历史数据快照**。

## 内容

- `src/index_timing_data/`：HTTPS 数据客户端、查询配置、命令行入口、快照与哈希校验。
- `tests/`：客户端、配置及快照逻辑的测试源码。
- `configs/valuable_data.json`：不含密钥的查询字段和参数配置。
- `docs/DATA_LAYER.md`：数据结构、凭据隔离与可得时间的研究边界。
- `docs/PROJECT_STATUS.md`、`docs/FAILED_APPROACHES.md`：历史研究状态与失败路线总结，保留原日期和口径。

## 环境与数据

需要 Python 3.11 或更高版本；依赖见 `pyproject.toml`。数据接口需要使用者自行获得有效访问权限，并在本地设置环境变量 `TWOSHARE_TOKEN`。不要把真实密钥提交到仓库。

公开包不提供初始数据快照。若自行抓取数据，应遵守接口及数据来源的使用和再分发条款；历史查询配置不代表有权限向第三方分发抓取结果。`data/README.md` 说明了公开范围。

原项目的快照验证和研究测试可能需要对应依赖或自行准备的数据。本次只做源码整理与 Python AST 静态检查，没有执行取数、训练、回测或交易。

## 结论边界

历史研究没有证明稳定有效的择时收益。宏观 current-table 数据不能直接当作历史首次发布版本；ETF 份额和融资数据仍需核查可得时点，数据工程完成也不等于策略有效。

作者、研究来源与依赖归属保留，本导出不追加统配许可证。原 private 仓库及其 Git 历史保持不变。
