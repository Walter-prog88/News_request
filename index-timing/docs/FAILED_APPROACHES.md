# 我尝试过但不可行的方法

这份文档只保留研究结论和失败原因。失败实现、揭盲代码、临时验证脚本、
调参过程和失败结果包没有上传到这个干净仓库。

## 1. 单纯依靠慢速价格趋势

尝试过基于长期均线、慢趋势和风险状态的 long/cash 择时。它可以改变回撤，
但没有在五只 ETF 上形成稳定、可迁移的相对买入持有超额。宽基指数收益常集中
在少数右尾交易日，慢信号长期降仓会错过这些日期；加入交易成本和执行延迟后，
优势进一步减弱。

结论：它更像风险覆盖层，不足以作为独立 alpha 引擎。

## 2. 五指数 12-1 横截面领导力轮动

主规格尝试用过去 12 个月、跳过最近 1 个月的相对强弱预测未来领导指数。
完整窗口与发布后窗口没有同时通过冻结门。

随后尝试：

- 大盘/中小盘两簇版本；
- 6-1 较短回看版本。

两条降档路线也没有得到稳定的样本外预测能力。

结论：价格类横截面领导力在现有样本中不够稳健，不能继续通过改变窗口救援。

## 3. P2 ETF 成交额流动性预测

这一路线不是“统计不显著”，而是在读取预测目标前因数据合同不一致而中止。
冻结合同要求 510500 有 146 个月观测，实际只有 134 个月。根因是
2015-04-13 和 2015-04-14 为真实无交易日期，严格 252 会话窗口因此让
连续 12 个月失去资格。

结论：

- 原 P2 没有产生正式统计结果；
- 按 single-reveal 纪律不得回填、修改合同后重跑；
- 新数据只能用于另行登记的 successor；
- successor 必须预先定义停牌与无交易日处理。

## 4. 用当前宏观历史表直接回测

PMI、CPI、PPI、社融、货币供应量和 GDP 的当前表很容易获取，但它们通常
没有逐期首次发布时间、首次发布值和历史修订版本。实测旧 PMI 观测的
`CREATE_TIME` 是多年后的数据库导入时间，不是当年的经济数据发布时间。

结论：把 current table 按经济月份回填到历史会产生前视偏差，只能用作
探索性参考，不能直接进入正式回测。

## 5. 用交易所回购行情替代 DR007

`repo_daily` 返回的是交易所回购证券行情。项目需要的是银行间市场 DR007
及公开时点，两者市场、定义和使用语义不同。

结论：不能用 `repo_daily`、FDR007 或 SHIBOR1W 冒充 DR007。

## 6. 用 PE 接口推导完整 P3

`index_dailybasic` 能提供部分指数的 PE、PE_TTM 和 PB，但没有指数历史股息率；
000852 和 932000 也没有返回估值行。

结论：它只能交叉验证部分 PE，不能关闭 P3 v1 的历史 D/P 数据门。

## 7. 直接增加两倍杠杆

在没有稳定、成本后、样本外有效信号之前，杠杆只会放大既有噪声和回撤。

结论：两倍杠杆保持锁定，不能用它来修复没有 alpha 的策略。
