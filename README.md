# 季子傲 · 研究作品集

机器人操作学习、大模型与 Agent、金融量化的精选代码与实验记录。按简历顺序展示三个方向，便于从研究问题直接查看实现与证据。

本作品集于 **2026-10-30** 整理。代码开发和材料整理使用了 AI 编程工具；上游模型、方法与数据的作者归属见各目录说明。

## 1. VLA 双臂操作与世界模型

[项目说明](vla/README.zh-CN.md) · [适配与执行代码](vla/transport/openpi/) · [演示视频](vla/assets/) · [最新实验结果](docs/RESULTS.md#vla)

- 双 Panda 机械臂在 MuJoCo 中完成开盖、清障、抓取、交接与入箱；使用 **200 条示范、82,036 帧、五路相机**进行 π0.5 适配与微调。
- 连接图像、机器人状态、动作块与底层控制器，组织 LoRA、全参数续训、采样策略与 BC-RNN 对照，结合专家前缀和接触记录分析失败。
- 一轮 **60 局开发评测**得到 B0／均匀续训／阶段加权续训 **0/20、1/20、1/20**。观察到个别成功，尚未证明稳定提升。
- Cosmos 3 Edge 完成 **3 组动作 × 2 个配对种子，共 6 段视频**的生成与接口检查；尚未验证其能准确预测动作后果或改善闭环任务。

所有机器人结果来自仿真。不同初态、专家接管条件和训练历史的结果不合并为一个成功率。

## 2. 大模型、Agent 与微调机制

[金融 RAG 完整工程](rag-full/README.md) · [工具与微调实验](methods/README.md) · [原有 RAG 项目](https://github.com/Walter-prog88/RAG_for_report) · [结果解释](docs/RESULTS.md#learning)

- 梳理预训练、后训练、强化学习、工具调用与推理成本，调研开源投研 Agent 的任务分工与状态传递。
- 原有金融RAG工程含 **3,031 个处理后Markdown文件、60条合成检索问答与10条云端/本地对照问题**。实现FAISS向量与词法检索、BGE重排序、时效权重、可选HyDE，以及受控研究工作流和结构化工具调用。文件数不代表去重文档量，合成题不等同人工独立测评。
- 投研工具原型连接规则卡、Python 数据快照、结构化输出与追加式记录，覆盖宏观、公司、组合风险 **3 类快照接口**；精选包仅使用合成示例。
- 小规模数字分类实验比较 LoRA 与全参数更新：rank=8 可训练参数 **3,792 对 17,610，减少 78.5%**；翻转任务新任务准确率 **96.4% 对 96.9%**。这是小 MLP 的学习实验，不能外推成大语言模型效果。
- 同实验也保留旧任务遗忘结果，避免只展示参数减少而隐去能力代价。

`rag-full/` 保留完整 `src/`、`scripts/` 与 `app/`，提供中文启动说明、依赖和配置模板。原文库、模型、索引和行情数据需按条款自备，默认关闭自动采集。

## 3. A 股因子与 ETF 研究

[A 股与 ETF 完整研究代码](quant-research/README.md) · [量化算子模拟示例](methods/quant/README.md) · [指标口径](docs/RESULTS.md#quant)

- 从分钟量价数据构建因子，比较线性打分与 GBDT 截面模型，使用 Rank IC、分层与滚动测试检验信号。
- 将交易成本、成交约束和风格暴露纳入组合评价，复核收益日期对齐与基准口径。
- ETF 研究账本包含 **669 条记录、632 个唯一实验 ID**；重复 ID 包含追加修正，不能表述为 669 组独立实验。
- 量化引擎保留 **18 条金标准一致性检查**。公开精选包的示例使用模拟数据，历史回测不作为实盘或稳定盈利证明。
