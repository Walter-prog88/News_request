## 小模型 LoRA 与 Agent

数字分类任务采用8×8图像和64→100→100→10的 MLP。以下是已保存的历史实验摘要，并非本次整理重新训练的结果。

| 配置 | 可训练参数 | 新任务准确率（flip） | 旧任务准确率 |
| --- | ---: | ---: | ---: |
| LoRA rank=8 | 3,792 | 96.4% | 43.2% |
| 全参数更新 | 17,610 | 96.9% | 63.7% |

可训练参数减少 `(17610 - 3792) / 17610 = 78.4668%`。不同方法各自选择学习率；因此本表不是完全相同优化条件下的因果结论。LoRA在这个设置下的旧任务保留更差，不能写成“减少遗忘”。小模型结论不能外推为大语言模型或机器人性能。

Agent 源项目有宏观、公司与组合风险三类快照接口。当前没有可核实的 Agent 任务完成率或人工时间节省百分比。精选账本演示只说明输出记录、缺失状态与哈希链的工程行为，不说明投研判断正确或可盈利。

## 量化研究

- ETF账本：669行，632个唯一实验ID；同ID可能有追加修正。
- A股因子数量存在1951与2151两种文档口径，公开简介使用“千余个因子定义”。
- 回测引擎：18条金标准一致性检查，是实现一致性指标，不能证明没有全部偏差或策略有效。
- 旧的漂亮收益在后续成本与风格归因检查后被下调，作品集不恢复旧年化收益宣传。
- 公开模拟示例不使用真实行情，不能据此复现历史策略收益。
